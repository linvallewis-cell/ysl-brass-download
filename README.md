# YSL Brass

**Variable-mu mastering compressor by Lewis Audio (DJ Bossy).**
Tube and opto-style glue for the 2-bus, drum groups and 808s. It has selectable rectifier characters, a sidechain EQ, tube bias, M/S and stereo width.

## Installing

The installers aren't code-signed yet, so your computer will warn you the first time:

- **Mac:** right-click the `.pkg` and choose **Open**, or go to System Settings → Privacy & Security → **Open Anyway**. The plugins install to `/Library/Audio/Plug-Ins`.
- **Windows:** on the SmartScreen prompt, click **More info**, then **Run anyway**. The VST3 installs to `C:\Program Files\Common Files\VST3`.

Then rescan plugins in your DAW. In FL Studio, go to Options → Manage plugins → **Find plugins** and load YSL Brass on a Mixer insert.
